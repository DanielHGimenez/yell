# Installation

Yell can be installed in MacOS, Linux, and Windows.

## How to install
- Download the [latest release bundle](https://github.com/DanielHGimenez/yell/releases).
- Extract the zip content to the location of your choice.
- Put the folder location into your <code>PATH</code> environment variable.
- Enjoy!!
